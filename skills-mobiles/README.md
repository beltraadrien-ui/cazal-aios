# Outils de l'application Claude (skills mobiles)

Chaque fichier `.zip` de ce dossier est un outil qui tourne dans l'application Claude, sur le téléphone
et sur l'ordinateur : résumé de vocal, idées et scripts de contenu, accroches, articles, veille,
questions techniques sur la base de savoir. Un zip = un outil.

- **Ils arrivent à jour tout seuls** avec chaque mise à jour de l'AIOS (« mets à jour mon AIOS »). À la
  fin, l'assistant dit lesquels ont changé et doivent être rechargés sur claude.ai.
- **Recharger un outil**, de préférence depuis l'ordinateur : claude.ai (ou l'application Claude) ▸
  **Personnaliser ▸ Compétences ▸ Téléverser**, choisir `skills-mobiles/<nom>.zip`, puis **Remplacer**
  l'ancienne version du même nom. Les intitulés exacts peuvent varier selon la version de l'application.
- **Ne pas les ouvrir ni les modifier à la main** : ce sont des fichiers du système, fabriqués par Adrien
  (`python shared/scripts/export_skills.py`). Une envie de changement : la noter dans
  `perso/demandes-a-adrien.md`.
