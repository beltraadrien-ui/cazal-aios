# Rédiger un article de blog — Cazal Réfrigération (SCRIPTING)

## Ce que fait cette skill

Produit un **article de blog complet** pour cazalrefrigeration.be, **SEO grand public** : utile,
rassurant, qui amène au devis. Deux sources possibles : (1) un sujet evergreen choisi via `idee-contenu`
/ `base-idees.md` ; (2) l'**extension d'un chantier** (le même vocal qu'un reel, développé en version
longue). Format figé : `references/format-article.md`.

> Skill de surface (mobile ou desktop). Ne jamais publier sans validation de Loïc.

## Étapes

1. **Déterminer la source** : idée evergreen (de `base-idees.md` / `idee-contenu`) ou chantier (vocal
   de Loïc). Confirmer le sujet et le mot-clé principal visé.
2. **Lire le contexte** : `references/format-article.md` (structure), `references/voice.md` (ton),
   `references/angles-signature-cazal.md` (angles + filtre), `references/rapport-perf-digest.md`.
3. **Rédiger** l'article suivant le format figé : titre H1 (avec mot-clé), méta-description, intro,
   H2 (problème → réponse → à retenir), FAQ (3-4 vraies questions clients), conclusion + CTA.
   800-1200 mots, phrases courtes, zéro jargon non expliqué.
4. **Mailler** vers d'autres prestations/contenus du site quand c'est pertinent.
5. Sortir l'article prêt à coller dans le portail blog ; marquer `[à vérifier par Loïc]` tout chiffre
   (prix, aide, norme) non confirmé.

## Règles fermes

- **Zéro jargon non expliqué** ; bénéfice client avant la technique.
- **Ne rien inventer** (prix, aides, normes, performances) → fourchette/condition + `[à vérifier]`.
- Citer la **zone d'intervention** (SEO local : Belgique + France frontalière) quand c'est naturel.
- Réutiliser les sujets/angles qui marchent (digest) ; ré-angler ceux qui ont pris.
- Brouillon → validation de Loïc avant publication.
