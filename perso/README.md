# Ta zone perso

Ce dossier est à toi : ce que tu y ranges n'est jamais envoyé sur GitHub et la mise à jour de l'AIOS
n'y touche jamais.
On y range tout ce que tu demandes à ton assistant de créer ou de garder : notes, annuaires
(sous-traitants, fournisseurs), modèles de mails, brouillons.
`perso/demandes-a-adrien.md` sert à noter ce que tu voudrais changer dans le système : Adrien l'intègre
au système.
