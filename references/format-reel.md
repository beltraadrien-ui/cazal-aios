# Format figé — Script de reel (Instagram / Facebook)

> Gabarit de sortie pour `script-reel-chantier` et `scripter-reel`. Structure **toujours identique**
> (comme `resume-vocal-devis`), pour que Loïc retrouve ses repères à chaque fois. Voix : `voice.md`.
> Psycho : `framework-hook.md`. Filtre éditorial : `angles-signature-cazal.md`.

La sortie présente d'abord **3 options de hook** (Loïc en choisit une), puis la fiche de tournage
complète. Reel cible : **< 45 s parlé, face caméra**, grand public, zéro jargon.

---

## Étape 1 — 3 options de hook

```
3 HOOKS pour : [sujet en clair]
Type : [Démo / Conseil / Avis]   ·   Angle : [archétype + cadrage]

A) « [hook < 15 mots, voix de Loïc] »
   Levier : [structure — ex. Question, Choc, Comparaison]   ·   Pourquoi : [ce qui marche dans le digest]
B) « [hook] »
   Levier : […]   ·   Pourquoi : […]
C) (contrarian) « [hook qui casse une idée reçue] »
   Levier : Contrarian   ·   Pourquoi : […]

→ Choisis A, B ou C (ou demande-en d'autres).
```

## Étape 2 — Fiche de tournage (une fois le hook choisi)

```
FICHE DE TOURNAGE — [sujet]
Hook choisi : [A/B/C]   ·   Type : [Démo/Conseil/Avis]   ·   Durée cible : ~[N] s

HOOK : « [hook retenu, dans ta voix] »
[SCREEN/ACTION : ce qu'on montre pendant le hook]

Beat 1 — [rôle : Contexte / Promesse / Constat]
« [phrase exemple dans ta voix] »
[SCREEN/ACTION si le visuel change]

Beat 2 — [rôle : Wow / Étape clé / Twist]
« [phrase exemple] »
[SCREEN/ACTION]

Beat 3 — [rôle : Preuve / Résultat / Pourquoi ça compte]
« [phrase exemple] »

CLOSE / CTA : « [1 ligne — appel au contact/devis] »

---
Texte à l'écran (2 premières s) : [3-5 mots en gros]
Légende du post : [1-2 phrases + CTA, voix de Loïc]
Format visuel : [Selfie face cam / Selfie + plan du chantier / Avant-après / Plans B-roll + texte]
Instructions de tournage :
- À filmer : [plans nécessaires — ex. l'unité posée, l'avant/après, le geste]
- Énergie : [posée / enthousiaste]
- Notes : [particularités]
```

## Règles
- 3-4 beats max, < 45 s. Si trop long, couper un beat.
- Faits **réels** du chantier/vocal — jamais de placeholder générique non rempli.
- Voix de Loïc, grand public, zéro jargon (cf. `voice.md` + `angles-signature-cazal.md`).
- Réutiliser/adapter ce qui marche (`rapport-perf-digest.md`), ré-angler ce qui a sous-performé.
- Montrer > dire : privilégier les plans du chantier au texte.
