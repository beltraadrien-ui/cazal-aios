# Format figé — Réalisation avant/après (site web)

> Gabarit de sortie pour la variante B de `script-reel-chantier`. Fiche **réalisation** publiée sur le
> site (portfolio de chantiers). Rassure les futurs clients par la preuve. Voix : `voice.md`.

Cible : **150-300 mots** + légendes de photos. Orienté résultat client, pas technique.

---

```
TITRE : [type de prestation + contexte — ex. « Remplacement d'une chaudière par une pompe à chaleur à [ville] »]

LE CONTEXTE (2-3 phrases)
- Le client (type, sans nom si particulier), son besoin de départ, le problème à résoudre.

CE QU'ON A FAIT (3-4 phrases ou puces)
- La solution posée, en clair. Les choix faits et pourquoi (bénéfice client).
- Mentionner brièvement le soin apporté (chantier propre, finitions).

LE RÉSULTAT (2-3 phrases)
- Le bénéfice concret obtenu (confort, économie d'énergie, gain de place…).
- Durée du chantier si pertinent.

LÉGENDES PHOTOS
- AVANT : [description courte]
- APRÈS : [description courte]
- [autres plans : détail soigné, unité extérieure…]

CTA : « Un projet similaire ? Demandez votre devis gratuit. » + lien contact.
```

## Règles
- Mettre en avant l'**avant/après** : c'est la preuve qui vend.
- Bénéfice client > détail technique. Jargon expliqué si inévitable.
- Citer la **zone/ville** (SEO local).
- Faits réels uniquement ; ne pas inventer de chiffres de performance.
